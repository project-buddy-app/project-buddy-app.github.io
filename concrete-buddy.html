Help — Running Concrete Buddy

Running Concrete Buddy

It works the way your hands already expect: type a number, tell it what the number is — feet, inches, or a fraction — and it keeps everything in feet-inch-fraction for you. Every key this pad shares with Framer Buddy works exactly the way it works in Framer.

Enter a measurement

For 5 feet, 3 and a half inches: tap 5 Feet 3 Inch 1 ⁄ 2. Add, subtract, multiply and divide measurements just like plain numbers — answers come back in feet, inches and fractions. Multiply one measurement by another and the answer is an area instead: it reads in square feet, with square inches and square yards on the line underneath — and dividing that area by a length gives the other length back. Tap ⌫ to back up one step, and On/C once to clear the entry, twice to clear the whole calculation.

Fraction resolution & display

Tap Fraction res in the right-hand column to cycle how fine fractions read out: 1/2, 1/4, 1/8, 1/16, 1/32, 1/64. Tap Disp under it to cycle the answer display between feet-inch-fraction, decimal feet and decimal inches.

Rise, Run & Diag — the triangle

Enter the rise and tap Rise, enter the run and tap Run. Then tap Diag for the third side — give it any two sides and it works out the one that's missing: rise 3 ft and run 4 ft hands back a 5 ft diagonal. The three sides are kept on the STORED page.

Convert — the yellow key

Tap Conv, then any unit key — yds, Feet, Inch, m, cm or mm — to see the measurement on screen in that unit, imperial or metric: lengths convert as lengths, areas as areas, and volumes and pour totals as volumes. Arm Conv again and tap another unit key to convert again, back and forth as often as you like; with Conv lit, ⁄ flips between fraction and decimal display.

Memory — Store, Rcl & Mem+

Store saves the number on screen to memory, Mem+ adds the number on screen to memory, and Rcl brings it back. While memory holds a value the MEM flag lights at the top of the display, and the value itself is listed on the STORED page. Beside the memory keys in the top row sit Columns and Tubes.

Columns — the guided pour

Tap Columns and the display walks you through it — prompt text on top, your numbers underneath. Enter Width In FT-In-Frac- Press Enter, then Depth, then Height the same way: type each measurement with Feet, Inch and ⁄, and tap Enter after each one. That column's volume is worked out and banked in the background. At If Finished Press Enter, To Add Column Press Add, tap Add to run the next column the same way, or Enter when the run is done. At the last prompt, Add shows the running count — every column banked, totalled in cubic yards — Store saves that count on the STORED page, and On/C exits. Made a mistake? ⌫ deletes a digit while you type, and with nothing typed it steps back one prompt with your numbers restored — stepping back from the Finished prompt un-banks that last column, so it is never counted twice. The back instruction only appears in the prompt while there is a step to go back to. On/C clears a half-typed entry; pressed with nothing typed, it exits Columns, and a run that was never stored is dropped.

Footings — the guided pour

Tap Footings and the display walks you through it — prompt text on top, your numbers underneath. Enter Footing Width In FT-In-Frac- Press Enter, then Footing Height, then Lineal Distance the same way: type each measurement with Feet, Inch and ⁄, and tap Enter after each one. That footing's volume is worked out and banked in the background. At If Finished Press Enter, To Add Footing Press Add, tap Add to run the next footing the same way, or Enter when the run is done. At the last prompt, Add shows the running count — every footing banked, totalled in cubic yards — Store saves that count on the STORED page, and On/C exits. Made a mistake? ⌫ deletes a digit while you type, and with nothing typed it steps back one prompt with your numbers restored — stepping back from the Finished prompt un-banks that last footing and returns you to its Lineal Distance, so it is never counted twice. The back instruction only appears in the prompt while there is a step to go back to. On/C clears a half-typed entry; pressed with nothing typed, it exits Footings, and a run that was never stored is dropped.

Keys still to come

Walls Slabs Pads Tubes Rebar and Mesh are Concrete's own keys and they don't do anything yet — each one gets its function added one at a time. Every other key on the pad is live. Outside the Columns and Footings sequences, Enter in the Slabs column works exactly like = — it finishes the calculation on screen; inside Columns or Footings, Enter steps you through the prompts.

What's stored

Tap STORED at the top any time to see the Rise / Run / Diag triangle, the Memory value and any Columns or Footings running count you saved with Store, held on the job. In that window, Clear triangle wipes the three sides, ready for the next one, and Clear columns and Clear footings each wipe a saved running count. At the bottom of that page, Send by email opens your email app with the whole stored page filled in — just add who it’s going to and hit Send. Export PDF and Export spreadsheet send the whole stored page out as a file instead — exporting opens your share sheet, so you can email the file or send it to another app; where sharing isn’t offered, the file downloads instead.

Browser — Suppliers & Lookup

Tap Browser and this window is a door to websites — nothing else. It opens real sites, never a search about a site.
Project Buddy Professional Services Homepage sits at the very top and opens the Project Buddy website home page. It is locked in place — it cannot be removed — and it stays tappable like every other link.
Google sits under it and opens Google itself — your fallback for finding anything.
Home Depot sits right under Google and the button says only that. It opens Home Depot’s own home page — the Canadian home page for a Canadian postal code, the US home page for a US ZIP — using the postal code or ZIP at the top of the window. Enter it once (or tap Use my location) and it’s remembered on this device. It never opens a Google search about Home Depot.
Your own suppliers: tap the yellow Add Your Supplier Url button. Find your supplier on Google first, copy their website address right from there, and paste it in — no typing long addresses from memory. Then name the button yourself, the same look as the Home Depot button, and tap Add supplier. Your yard, your concrete plant, whoever you actually buy from — the list is saved on this device and each button opens that supplier’s own website.
Taking one off: every supplier you add carries a small Clear button beside it — one tap and it’s off the shelf. The Project Buddy homepage button, Google and Home Depot are fixed and stay put.
These links open live pages, so they need data; the calculator itself never does.

On a PC keyboard

The number keys, + − * and = all work, / starts a fraction, Enter taps =, Backspace deletes, and Esc clears — or closes an open window.
