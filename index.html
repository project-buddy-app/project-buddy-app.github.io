About

45 years on the tools. The knowledge isn’t done.

👷
Project BuddyCarpentry • Estimating • Drafting

Project Buddy is built on 45 years of hands-on carpentry and estimating experience. Everything those years taught — how the work is really done on site, what a job actually takes, where the traps are — is being turned into tools, so the knowledge keeps working.

Every Buddy starts from how the work is actually done on site, gets tested against real numbers and the code book, and only ships when it holds up. If a feature could cost a user more trust than it earns, it doesn’t ship — that rule has already cut features from this lineup, and it’ll cut more.

The calculators come first and they stay honest: tested math does the precision work, and nothing here is ever sold as a subscription. You buy it, it’s yours.
